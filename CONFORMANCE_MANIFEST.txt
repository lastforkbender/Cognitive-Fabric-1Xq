Claim boundary
--------------

The manuscript's algebraic proofs are over exact real arithmetic. TLAPS proves
the abstract publication safety theorem only. TLC is a finite-instance
cross-check; its liveness result is not a symbolic liveness proof. The Python
code is a finite-precision implementation with explicit tolerances and
validation, but no statement-level Python-to-TLA+ refinement is proved.

ResolutionSnapshotConsistency is metadata-only. Foreign outcomes are excluded
from direct application but may cause bounded-capacity interference. The
publication trace correspondence assumes at most one local observation per
modeled resolver completion. Each TLA+ instance has a finite MaxOutcomeId.
Concurrency arguments rely on stated in-process Python lock semantics.
Snapshot identity assumes SHA-256 collision resistance. Crash consistency,
durability, scheduler fairness, durable exactly-once delivery, and generic
atomic-object linearizability are not claimed.
